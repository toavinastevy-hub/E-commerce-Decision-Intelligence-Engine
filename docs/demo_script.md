# Five-minute demo script

Before you start: run `streamlit run app.py`. Say at the start that the data is simulated.

| Time | Screen (left menu) | What to do | What to say |
|---|---|---|---|
| 0:00 | 🏁 Start here | Click **🚀 Try the demo in one click**. | "This is made-up (simulated) shop data: 24 products, 18 months. One click loads it, checks it for mistakes and opens the results." |
| 0:30 | 📊 The big picture | Point at the four headline cards, then the seven findings. | "Sales after discounts $852,008, profit margin 38.1%, up 6% on last year. Fourteen products earn less profit in discounted months." |
| 1:15 | 📊 The big picture | Hover over a small question mark. Open **📖 Words explained** in the menu. | "Every technical word is explained in plain language, so a non-specialist can follow." |
| 1:45 | ✅ What to do next | Open rank 1 (Face Moisturizer) and rank 3 (Bluetooth Speaker Mini). | "Each action has the problem, the proof, what to do, the benefit, the risks and a priority. Stock about to run out comes first. The benefit says 'up to about', never a promise." |
| 2:30 | ✅ What to do next | Open the **Promotion** item. | "A different rule flagged the Resistance Bands Set for promotion, but it is about to run out of stock, so the engine leaves it out and says why." |
| 3:00 | 💸 Do discounts pay off? | Move the calculator to a 20% discount and 50% profit. | "A 20% discount means selling 67% more items just to earn the same profit." |
| 3:30 | 🧪 Try a price change | Set price +10%, then choose the option about how customers react to price. | "I cannot know how customers react, so that number is always the user's own guess. The screen shows what you would need to sell to break even." |
| 4:15 | 📊 The big picture | Click the download button. | "A one-page report for a manager, with the simulated-data warning built in." |
| 4:40 | (any) | Close. | "146 automated tests and an independent SQL check back the numbers. The limits are written in the README." |

## If something goes wrong

- A page says no data is loaded: open **🏁 Start here** and click **🚀 Try the demo in one click**.
- App will not start: check that `(.venv)` shows in the terminal and run `pip install -r requirements.txt`.
